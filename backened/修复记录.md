# 漏洞数据值转换问题修复记录

## 问题概述
项目中存在多处代码将漏洞字段的原始值转换为 `None`、空字符串 `""` 或其他默认值，导致丢失原始数据。现已全部修复，确保保留漏洞文件中的原始值。

## 修复清单

### 1. **extractor.py - map_json_fields 方法** ✅
**问题**: `knownRansomwareCampaignUse` 字段被转换为布尔值或 `None`
```python
# 修复前：特殊处理将 "Unknown" 转换为 None
elif json_field == 'knownRansomwareCampaignUse':
    if isinstance(value, str):
        value_lower = value.lower()
        if value_lower in ['yes', 'true']:
            result[db_field] = True
        elif value_lower in ['no', 'false']:
            result[db_field] = False
        else:
            result[db_field] = value

# 修复后：直接保留原始值
else:
    result[db_field] = value
```

### 2. **json_extractor.py - _handle_list 方法** ✅
**问题**: 空列表被设置为 `None`
```python
# 修复前
if not data:
    result[prefix] = None
    return

# 修复后：保留空列表原始值
if not data:
    result[prefix] = data
    return
```

### 3. **cleaner_validator.py - clean_string 方法** ✅
**问题**: 空字符串被转换为 `""`
```python
# 修复前
if not text:
    return ""

# 修复后：保留原始值
if not text:
    return text
```

### 4. **cleaner_validator.py - clean_date 方法** ✅
**问题**: 无法解析的日期被转换为 `None`
```python
# 修复前
return str(date_value) if date_value else None

# 修复后：保留原始值
return date_value
```

### 5. **extractor.py - extract_cert_json 方法** ✅
**问题**: 字段值为空字符串时被过滤掉
```python
# 修复前
if val is not None and val != '':
    result[field] = val

# 修复后：只过滤 None，保留空字符串
if val is not None:
    result[field] = val
```

### 6. **extractor.py - extract_cert 方法** ✅
**问题**: 合并 JSON 和 HTML 结果时过滤空字符串
```python
# 修复前
if json_val is not None and json_val != '':
    final[field] = json_val
elif html_val is not None and html_val != '':
    final[field] = html_val

# 修复后：只过滤 None
if json_val is not None:
    final[field] = json_val
elif html_val is not None:
    final[field] = html_val
```

### 7. **extractor.py - _parse_cert_overview_sections 方法** ✅
**问题**: 空内容被过滤
```python
# 修复前
if db_field and content:
    result[db_field] = content

# 修复后：只过滤 None
if db_field and content is not None:
    result[db_field] = content
```

### 8. **extractor.py - _extract_cert_from_html 方法** ✅
**问题**: 多个字段在提取时过滤空值
- `overview` 字段
- `clean_desc` 字段
- `impact` 字段
- `resolution` 字段
- `cveids` 字段
- `sysaffected` 字段

修复方式：保留原始值，只在有实际内容时才添加到结果中

## 修复原则

1. **保留原始值**: 不转换 `None`、空字符串、空列表等原始值
2. **只过滤 None**: 仅当值为 `None` 时才不添加到结果
3. **保持数据完整性**: 确保漏洞文件中的所有原始值都被保留

## 测试建议

2. 测试包含空字段的漏洞数据
3. 验证日期字段的处理
4. 检查 CERT 数据的 JSON 和 HTML 混合提取
